# Changelog

All notable NearSentry changes are recorded here.

## [0.0.0.3] - 2026-09-22

### Added
- Long-lived `master` and `develop` branch model.
- Branching strategy documentation.

### Changed
- CI now runs on `master` and `develop`.
- Repository version advanced to `0.0.0.3`.

## [0.0.0.2] - 2026-09-22

### Added
- Repository-wide `AGENTS.md` operating contract.
- Scoped agent instructions for Flutter, domain, Android native, and documentation.
- Hidden `.agents/` infrastructure with eleven specialized engineering agents.
- Shared context and engineering guardrails.
- Reusable feature, feasibility-spike, and incident-debug workflows.
- Agent task, review, and handoff templates.

### Changed
- Repository version advanced to `0.0.0.2`.

## [0.0.0.1] - 2026-09-22

### Added
- Initial repository structure.
- Documentation system for product, design, specifications, ADRs, testing, operations, and versions.
- Flutter application shell.
- Pure Dart domain package skeleton.
- Android/Kotlin sentry module skeleton.
- Initial protection state model and alarm policy contracts.
- CI and local verification scripts.

### Important
This is an architecture/bootstrap version, not a production-ready release.
