# Workflow: Feature Delivery

1. Product agent identifies requirement IDs and acceptance criteria.
2. Architect decides whether architecture/ADR changes are required.
3. Owning implementation agent changes code.
4. Security agent reviews security-sensitive paths.
5. QA agent adds/executes verification appropriate to the layer.
6. Docs agent checks traceability and design/spec consistency.
7. Release agent checks version/changelog impact.
8. Orchestrator verifies the handoff contract before closure.
