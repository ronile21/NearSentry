# Release Checklist

Before declaring any NearSentry version releasable:

- VERSION updated.
- CHANGELOG updated.
- version document added under docs/05-versions.
- accepted design changes captured in ADRs.
- static analysis passes.
- domain/unit tests pass.
- Android tests pass for implemented native components.
- real-device test evidence recorded.
- permissions reviewed.
- battery behavior reviewed.
- known limitations documented.
- no credentials/secrets committed.
