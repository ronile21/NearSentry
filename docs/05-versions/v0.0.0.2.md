# Version 0.0.0.2

- Status: Active development
- Branch: `v0.0.0.2`
- Base release: `v0.0.0.1`

## Scope

V2 starts with Garmin watch UX and reconnect reliability work requested after V1 closure.

### Touch-first watch controls

- large on-screen SYSTEM ON/OFF toggle
- on-screen MUTE/UNMUTE during ALARM
- existing physical START/STOP and DOWN controls retained
- touch controls route through the same controller/state paths as physical controls

### Reconnect correctness

- persist whether an alarm is eligible for automatic reconnect recovery
- reconcile phone connection from polling, device-setting callback and successful phone-app messages
- real separation reconnect returns to PHONE CONNECTED + ARMED and clears watch alarm output
- TEST_ALARM remains explicitly non-auto-recovering
- align Dart and Android state-machine tests with ALARM + anchor recovery -> PROTECTED

## Security boundary

The SYSTEM OFF action remains blocked while a real alarm is active. Touch input must not introduce a bypass around the existing alarm/dismissal policy.

## Validation status

Source implementation prepared. Physical Fenix 7X build/install/touch/reconnect validation is still required and must not be claimed until observed on hardware.
