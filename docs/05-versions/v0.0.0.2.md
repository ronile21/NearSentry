# Version 0.0.0.2

- Date: 2026-09-22
- Status: Agent-infrastructure foundation

## Purpose

Establish a durable, repository-native operating model for AI/coding agents before implementation accelerates.

## Included

- root `AGENTS.md` repository contract
- scoped `AGENTS.md` files for app, domain, Android native, and documentation
- hidden `.agents/` hierarchy
- specialized agent roles
- shared project context and engineering guardrails
- feature, feasibility-spike, and incident workflows
- task, review, and handoff templates

## Agent roles introduced

- orchestrator
- product
- architect
- domain
- android
- bluetooth-garmin
- flutter
- security
- qa
- docs
- release

## Design intent

Agents receive explicit boundaries and handoff contracts so autonomous work cannot casually collapse product, architecture, implementation, security, and verification concerns into one opaque task.

## Verification

Repository tree and file visibility must be checked after the commit is attached to `main`.

## Known limitations

Agent definitions are governance/instruction infrastructure. They do not themselves execute background agents or provide a runtime scheduler.
