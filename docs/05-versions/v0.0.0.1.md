## Architecture decisions

- ADR-0001 Flutter UI with native Android sentry
- ADR-0002 device-agnostic anchor domain
- ADR-0003 local-first MVP
- ADR-0004 native enforcement projection
- ADR-0005 Garmin Connect IQ Mobile SDK anchor source
- ADR-0006 Garmin watch companion and background-attention boundary

## Validation boundary

The implementation is source-complete for the declared MVP path, but the implementation environment did not contain Flutter/Dart/Android SDK or Garmin hardware. Build, emulator/device, Garmin, OEM background, battery and full-screen behavior therefore remain unvalidated here.

GitHub Actions is disabled and was not used as validation.
