# Version 0.0.0.1

- Release date: 2026-09-23
- Status: Released

## Included

- deterministic pure Dart protection engine and tests
- complete Material 3 Flutter application shell
- onboarding, prerequisite setup, trusted-device setup, dashboard, grace/alarm UX, history, settings and diagnostics
- typed Flutter/native bridge
- Android connected-device foreground service
- native monotonic protection enforcement engine
- Garmin Connect IQ Companion App SDK adapter
- Fenix 7X Connect IQ companion app and Android-to-watch command protocol
- foreground watch-side disconnect/grace/alarm implementation
- Fenix START/STOP local protection control
- Fenix DOWN-button persistent watch-local MUTE/UNMUTE during ALARM
- watch-to-Android CONTROL/START and CONTROL/STOP synchronization
- automatic recovery from a real separation alarm when the trusted phone reconnects; protection returns to ARMED/PROTECTED instead of remaining latched in ALARM
- armed-only five-minute background watchdog with foreground-only one-second polling
- Connect IQ background message service and five-minute disconnect fallback
- durable local settings/enrolled anchor/armed intent
- bounded local telemetry
- idempotent audio/vibration/full-screen alarm path
- BiometricPrompt/device-credential alarm dismissal
- explicit developer simulator
- updated design/specification/ADR/testing/operations documentation
- repository-native agent infrastructure and branching model

## Validation

Physically verified on the user's Samsung Android phone and Garmin Fenix 7X during the v0.0.0.1 development cycle:

- Android APK build/install completed successfully on device.
- Garmin PRG build/install completed successfully before the final auto-recovery patch.
- Android -> Garmin PING / command transport was observed on the physical watch.
- Watch START/STOP local arming was observed physically.
- Foreground phone disconnect was observed as PHONE DISCONNECTED -> ALARM.
- Watch vibration and audible alarm were observed physically.

Release validation gap:

- the final auto-recovery patch was not reinstalled and physically revalidated on the watch/phone before closing v0.0.0.1
- the release is closed with that behavior explicitly marked as unverified on the final release commit

GitHub Actions is disabled and is not release evidence for this version.

## Known limitations

- Connect IQ does not provide a continuous one-second background daemon. NearSentry's short-grace custom watch disconnect detector is foreground-only.
- Armed watch background execution uses event-driven phone messages plus a five-minute temporal watchdog.
- Garmin native Phone Connectivity Alert remains the recommended immediate platform-level alert while the NearSentry watch app is fully backgrounded.
- Android OEM background behavior, long-duration battery impact, and all full-screen alarm policy variations are not exhaustively validated across devices.
