# Version 0.0.0.3

- Date: 2026-09-22
- Status: Branching model initialization

## Purpose

Introduce the repository's long-lived branch model.

## Included

- `master` branch as the intended stable/default branch.
- `develop` branch for active integration work.
- CI updated to run for both long-lived branches.
- documented branching strategy.

## Verification

Both branches must point to the same baseline commit when initialized, after the branching/CI update commit is created.

## Known limitation

The connected GitHub integration may not expose repository-default-branch mutation or branch deletion. If so, changing GitHub's default branch from `main` to `master` and deleting the old `main` ref must be completed via GitHub repository settings.
