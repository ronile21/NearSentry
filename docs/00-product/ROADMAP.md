# Roadmap

- Repository, documentation, state model, architecture spikes.
- Verify Android background execution and Garmin signal options.

- Native sentry service.
- Anchor adapter.

- Biometric-gated dismissal.

- Evaluate Connect IQ watch application/communication.

- Real device soak tests.
- False-positive tuning.
- Crash/reboot/radio failure scenarios.
- Compatibility matrix.

## Later
- Multiple anchors.
- Additional wearable vendors.
- Optional cloud/family features only after the local protection engine is proven.
